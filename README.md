## One Line, Big Laugh

One deadpan line, 133 characters: a phone's screen-time report calls its owner brave, then shows four hours spent watching a man restore a rusty shovel in complete silence. The praise promises self-improvement; the twist exposes the opposite.

`main.py` writes the exact line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
